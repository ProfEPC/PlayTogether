# Shared Sound Effects

Common sound effects used throughout the application.

## Categories

- **UI Interactions** - Clicks, hovers, button presses
- **Notifications** - Alert and notification sounds
- **Feedback** - Error, success, and general feedback sounds
- **Navigation** - Page transitions and navigation sounds
- **System** - Connection, disconnect, and system sounds

Format recommendations: MP3, OGG, or WAV

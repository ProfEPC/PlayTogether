# Shared Assets

Common media assets used across multiple games and throughout the application.

## Subdirectories

- **images/ui/** - Common UI elements (buttons, icons, panels)
- **images/backgrounds/** - General backgrounds and textures
- **audio/music/** - Ambient and lobby music
- **audio/sfx/** - Common sound effects (clicks, notifications, etc.)

These assets can be used in any game or context.

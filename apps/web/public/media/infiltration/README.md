# Infiltration Game Assets

This directory contains all media assets specific to the Infiltration game mode.

## Subdirectories

- **images/roles/** - Character/role artwork (Infiltrator, Civilian, Thief/Hacker/Engineer, etc.)
- **images/phases/** - Visuals for game phases (Lobby, Reveal, Mayhem, Voting, Results)
- **images/ui/** - UI elements, buttons, icons, overlays specific to Infiltration
- **audio/music/** - Background music tracks for Infiltration gameplay
- **audio/sfx/** - Sound effects (alerts, actions, phase transitions, etc.)

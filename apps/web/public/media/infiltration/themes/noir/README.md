# Noir Theme

Film noir, detective mystery, black & white aesthetic for Infiltration gameplay.

## Visual Style

- Classic film noir style
- High contrast black and white with dramatic shadows
- Detective/spy thriller atmosphere
- 1940s-50s aesthetic
- Moody, dramatic lighting

## Image Folders

- **roles/** - Noir-style characters, detectives, suspects, mobsters
- **phases/** - Noir environments: alleyways, offices, casinos
- **ui/** - Noir UI: typewriter text, shadows, film frames, detective elements

# Player Eliminated Sound

Sound effect triggered when a player is eliminated from the game.

## Usage

- Plays when a player is voted out
- Should convey loss/elimination
- Dramatic or impactful tone

## Theme Notes

- **Alien**: Alien disintegration/teleport away sound
- **Fairy Tale**: Character vanishes in puff of smoke/magic
- **Noir**: Suspect arrested, mugshot taken, jail cell closes

## Format

MP3, OGG, or WAV recommended

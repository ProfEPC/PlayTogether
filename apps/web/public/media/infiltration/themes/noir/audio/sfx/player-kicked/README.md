# Player Kicked Sound

Sound effect triggered when a player is kicked from the game by the host.

## Usage

- Plays when a host removes a player from the room
- Should convey dismissal/removal
- Alert or negative tone

## Theme Notes

- **Alien**: Airlock opening, ejection from ship
- **Fairy Tale**: Banishment spell, exile magic
- **Noir**: Suspect thrown out, kicked off case

## Format

MP3, OGG, or WAV recommended

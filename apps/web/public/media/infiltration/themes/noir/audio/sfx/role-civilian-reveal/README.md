# Role Civilian Reveal Sound

Sound effect triggered specifically when a Civilian role is revealed.

## Usage

- Plays during the reveal phase when Civilian is exposed
- Should sound neutral or regular
- Distinct from Infiltrator and Special roles

## Theme Notes

- **Alien**: Human/colonist revealed, neutral tone
- **Fairy Tale**: Villager/peasant revealed, normal townsperson
- **Noir**: Innocent bystander revealed, regular person

## Format

MP3, OGG, or WAV recommended

# Phase Mayhem Sound

Sound effect triggered when transitioning to the Mayhem phase.

## Usage

- Plays when special actions/powers become active
- Should convey chaos, action, and urgency
- Signals the most intense phase of gameplay

## Theme Notes

- **Alien**: Alarm blaring, red alert, invasion chaos
- **Fairy Tale**: Magical explosion, spell casting rush
- **Noir**: Gunshots, car chase, action thriller beat

## Format

MP3, OGG, or WAV recommended

# Player Power Activate Sound

Sound effect triggered when a player uses their special power/ability.

## Usage

- Plays when a special power is activated during Mayhem phase
- Should sound powerful and active
- Different from regular actions to highlight special abilities

## Theme Notes

- **Alien**: Energy weapon firing, alien ability activates
- **Fairy Tale**: Magical spell cast, enchantment activates
- **Noir**: Detective ability trigger (revolver, camera flash, etc.)

## Format

MP3, OGG, or WAV recommended

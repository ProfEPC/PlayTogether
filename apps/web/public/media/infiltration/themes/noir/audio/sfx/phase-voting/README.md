# Phase Voting Sound

Sound effect triggered when transitioning to the Voting phase.

## Usage

- Plays when players begin voting
- Should prompt attention and decision-making
- Signals discussion/voting time

## Theme Notes

- **Alien**: Neutral alert tone, council voting signal
- **Fairy Tale**: Bell chime, tribunal gathering
- **Noir**: Gavel strike, jury deliberation signal

## Format

MP3, OGG, or WAV recommended

# Error Timeout Sound

Sound effect triggered when a game phase times out.

## Usage

- Plays when a timer expires and action is forced
- Should convey urgency/deadline
- Warning or alarm tone

## Theme Notes

- **Alien**: Countdown alarm, evacuation alert
- **Fairy Tale**: Magical time running out, spell expires
- **Noir**: Clock strikes, time's up, deadline passed

## Format

MP3, OGG, or WAV recommended

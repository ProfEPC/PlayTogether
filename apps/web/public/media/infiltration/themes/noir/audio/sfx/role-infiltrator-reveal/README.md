# Role Infiltrator Reveal Sound

Sound effect triggered specifically when the Infiltrator role is revealed.

## Usage

- Plays during the reveal phase when Infiltrator is exposed
- Should sound menacing, suspicious, or dramatic
- Distinct from other role reveals

## Theme Notes

- **Alien**: Alien alert/threat sound, invasion exposed
- **Fairy Tale**: Evil sorcerer/witch reveal, dark magic sound
- **Noir**: Suspect exposed, criminal caught sound

## Format

MP3, OGG, or WAV recommended

# Noir Theme - Roles

Character artwork and visual representations for the Noir theme.

## Role Types

- **Infiltrator (Suspect/Spy)** - The criminal element
- **Civilian (Innocent Bystander)** - Regular townspeople
- **Special Roles** - Detective, FBI Agent, Private Eye

## Asset Types

- Film noir character portraits
- 1940s-50s fashion and styling
- High contrast black and white imagery
- Dramatic shadow effects on characters
- Noir-style badges and role indicators

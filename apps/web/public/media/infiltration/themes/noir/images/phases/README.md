# Noir Theme - Phases

Phase-specific visuals for the Noir theme.

## Game Phases

- **Lobby** - Detective's office or smoky nightclub
- **Reveal** - Dramatic suspect reveals with spotlight effects
- **Mayhem** - Tense spy thriller action sequences
- **Voting** - Voting interface styled as police interrogation
- **Results** - Results screen with noir victory/defeat visuals

## Asset Types

- Dark alleyway and office backgrounds
- Dramatic spotlight and shadow lighting
- Venetian blind/grid shadow patterns
- Film strip and movie frame effects
- Smoke and atmospheric effects

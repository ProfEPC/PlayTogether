# Fairy Tale Theme

Fantasy, magical, storybook aesthetic for Infiltration gameplay.

## Visual Style

- Whimsical, fantasy design
- Magical sparkles and glows
- Fairy tale creatures and characters
- Enchanted forest and castle environments
- Soft, vibrant color palettes

## Image Folders

- **roles/** - Fairy tale character designs, wizards, elves, creatures
- **phases/** - Magical environments and fantasy settings
- **ui/** - Enchanted-looking buttons, magical icons, storybook elements

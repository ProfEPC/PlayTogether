# Fairy Tale Theme - Roles

Character artwork and visual representations for the Fairy Tale theme.

## Role Types

- **Infiltrator (Evil Witch/Sorcerer)** - The treacherous magical being
- **Civilian (Peasant/Villager)** - Regular townspeople
- **Special Roles** - Heroes with magical abilities (Knight, Healer, Mage)

## Asset Types

- Fantasy character portraits
- Costume designs with magical elements
- Glowing, enchanted character effects
- Magical badges and role indicators
- Fairy tale artistic style

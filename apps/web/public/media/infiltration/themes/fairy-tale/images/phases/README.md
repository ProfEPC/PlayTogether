# Fairy Tale Theme - Phases

Phase-specific visuals for the Fairy Tale theme.

## Game Phases

- **Lobby** - Enchanted castle or village square
- **Reveal** - Magical character reveals with spellbook aesthetics
- **Mayhem** - Magical action sequences in fairy tale setting
- **Voting** - Voting interface styled as a magical scroll or spell
- **Results** - Results screen with fantasy triumph/defeat visuals

## Asset Types

- Enchanted forest and castle backgrounds
- Magical sparkle and glow effects
- Storybook-style illustrations
- Ornate magical frames and decorations

# Player Vote Sound

Sound effect triggered when a player casts a vote.

## Usage

- Plays when a player submits their vote
- Should be distinct and confirming
- Provides audio feedback for vote action

## Theme Notes

- **Alien**: Beep/digital confirmation tone
- **Fairy Tale**: Magical sparkle, vote registered chime
- **Noir**: Typewriter key press, vote confirmed click

## Format

MP3, OGG, or WAV recommended

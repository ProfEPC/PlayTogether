# Phase Results Sound

Sound effect triggered when transitioning to the Results phase.

## Usage

- Plays when showing game results
- Should convey finality and conclusion
- Signals end of round

## Theme Notes

- **Alien**: Transmission complete, mission summary tone
- **Fairy Tale**: Fairy tale ending, happily ever after magic
- **Noir**: Case closed, noir sting, mystery solved

## Format

MP3, OGG, or WAV recommended

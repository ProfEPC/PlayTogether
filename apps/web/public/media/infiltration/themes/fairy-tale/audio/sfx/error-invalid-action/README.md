# Error Invalid Action Sound

Sound effect triggered when a player attempts an invalid action.

## Usage

- Plays when an action cannot be performed (game state mismatch, invalid timing, etc.)
- Should convey error or rejection
- Alert or warning tone

## Theme Notes

- **Alien**: Buzzer/error beep, system rejection
- **Fairy Tale**: Magic fizzles, spell backfires
- **Noir**: Buzzer/denied sound, clue rejected

## Format

MP3, OGG, or WAV recommended

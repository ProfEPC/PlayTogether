# Phase Reveal Sound

Sound effect triggered when transitioning to the Reveal phase.

## Usage

- Plays when roles are about to be revealed
- Should build anticipation
- Signals dramatic moment of role disclosure

## Theme Notes

- **Alien**: Scanner/detection beep revealing aliens
- **Fairy Tale**: Magical scroll unrolling, spell activation
- **Noir**: Case file opening, mystery unfolding

## Format

MP3, OGG, or WAV recommended

# Game Close Sound

Sound effect triggered when the Infiltration game ends or is closed.

## Usage

- Plays when the game is closed or abandoned
- Signals the end of gameplay
- Can be neutral or conclusive in tone

## Theme Notes

- **Alien**: Ship departure/powering down sound
- **Fairy Tale**: Magic dissipating/spell ending
- **Noir**: Case closing/detective dismissal

## Format

MP3, OGG, or WAV recommended

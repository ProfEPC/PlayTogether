# Game Start Sound

Sound effect triggered when the Infiltration game begins.

## Usage

- Plays when the host starts the game
- Signals to all players that gameplay is beginning
- Should match the theme's aesthetic

## Theme Notes

- **Alien**: Sci-fi beeping/futuristic launch sound
- **Fairy Tale**: Magical spell/enchantment fanfare
- **Noir**: Detective badge/case opening sound

## Format

MP3, OGG, or WAV recommended

# Alien Theme - Audio

Audio effects for the Alien theme.

## Subdirectories

Contains all SFX organized by action:

- **game-start** - Game start sound
- **game-close** - Game end sound
- **phase-reveal** - Role reveal phase
- **phase-mayhem** - Special actions phase
- **phase-voting** - Voting phase
- **phase-results** - Results reveal
- **player-vote** - Player vote cast
- **player-eliminated** - Player elimination
- **player-power-activate** - Special power used
- **player-kicked** - Player kicked by host
- **role-infiltrator-reveal** - Infiltrator reveal
- **role-civilian-reveal** - Civilian reveal
- **role-special-reveal** - Special role reveal
- **error-invalid-action** - Invalid action attempt
- **error-timeout** - Phase timeout

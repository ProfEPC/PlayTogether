# Role Special Reveal Sound

Sound effect triggered specifically when a Special role is revealed (Thief, Hacker, Engineer).

## Usage

- Plays during the reveal phase when Special roles are exposed
- Should sound unique and powerful
- Distinct from Infiltrator and Civilian roles

## Theme Notes

- **Alien**: Alien specialist/engineer revealed, powerful alien sound
- **Fairy Tale**: Hero/mage/knight revealed, heroic magical fanfare
- **Noir**: Detective/FBI agent revealed, authority/hero theme

## Format

MP3, OGG, or WAV recommended

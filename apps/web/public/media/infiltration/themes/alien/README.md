# Alien Theme

Sci-fi UFO and extraterrestrial aesthetic for Infiltration gameplay.

## Visual Style

- Futuristic, space-age design
- Glowing neon elements
- Alien/extraterrestrial characters and symbols
- High-tech UI components
- Cosmic backgrounds and color schemes

## Image Folders

- **roles/** - Alien character designs, creatures, astronauts
- **phases/** - Phase backgrounds with alien environments
- **ui/** - Futuristic buttons, icons, HUD elements

# Alien Theme - Phases

Phase-specific visuals for the Alien theme.

## Game Phases

- **Lobby** - Space station or spacecraft lobby
- **Reveal** - Alien identity reveals with futuristic effects
- **Mayhem** - Alien actions and chaos in space environment
- **Voting** - Voting interface with space/tech aesthetics
- **Results** - Results screen with alien victory/defeat visuals

## Asset Types

- Space backgrounds and environments
- Glowing UI overlays
- Futuristic phase transition graphics
- Tech-style text and indicators

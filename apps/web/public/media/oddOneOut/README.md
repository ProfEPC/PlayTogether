# Odd One Out Game Assets

This directory contains all media assets specific to the Odd One Out game mode.

## Subdirectories

- **images/phases/** - Visuals for game phases (Lobby, Questions, Results)
- **images/ui/** - UI elements, buttons, icons, overlays specific to Odd One Out
- **audio/music/** - Background music tracks for Odd One Out gameplay
- **audio/sfx/** - Sound effects (alerts, selections, reveals, etc.)

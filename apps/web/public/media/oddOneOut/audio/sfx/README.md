# Odd One Out Sound Effects

Sound effects for Odd One Out game events and interactions.

## Categories

- **Question Reveal** - Sounds for revealing questions and choices
- **Selections** - Sounds for player selections
- **Correct/Incorrect** - Feedback sounds for answers
- **Reveals** - Sounds for revealing the odd one out
- **Transitions** - Phase transition sounds

Format recommendations: MP3, OGG, or WAV

# Odd One Out Game Phases

Phase-specific visuals for different stages of Odd One Out gameplay.

## Game Phases

- **Lobby** - Pre-game lobby screens and graphics
- **Questions** - Question reveal and answer choice displays
- **Voting** - Voting/selection phase graphics
- **Results** - Results screen showing the odd one out

## Asset Types

- Background images
- Question display graphics
- Answer choice visuals
- Phase transition graphics
- Highlight/selection effects
